# Pokedex CLI

A simple command-line Pokedex application written in Go.

The application uses the PokeAPI to explore locations, find Pokemon, catch them and view information about caught Pokemon.

## Features

- Explore Pokemon locations
- Find and catch Pokemon
- View caught Pokemon
- Inspect Pokemon stats
- Cache API responses

## Running the project

Clone the repository:

git clone https://github.com/Agron123/pokedex-cli.git

Go into the project directory:

cd pokedex-cli

Run the application:

go run .
